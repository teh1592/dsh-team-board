# 依赖与启用

**简体中文** | [English](en/dependencies.md)

Team Board 沿用 DSH 的模型配置，通过子智能体完成评审与开发。

## 运行要求

| 用途 | 所需能力 |
|---|---|
| 评审与独立讨论 | DSH 的文件系统、主助手、工作目录和子智能体服务，启用全新上下文的 `spawn` |
| 开发与机器检查 | 上述能力，加命令执行服务和项目检查配置 |
| 页面操作 | DSH Web 界面及已认证的命令连接 |

中断后回收子会话结果会使用 `sessionQuery`。缺少它时，已保存的结果仍可查看，未完成的阶段需重新执行。仅有继承父对话的 `fork` provider 时，需要另外启用全新上下文 provider。

## 启用步骤

1. 在 DSH 中启用子智能体和 `spawn`。开发任务同时启用命令执行能力。
2. 安装 Team Board，打开会话中的插件页面，再打开 Team Board 开关。
3. 填写需求并启动。选择开发方式时，在项目中配置 `.review/config.json` 的检查命令，见[操作指南](operations.md#开发与机器检查)。

安装包所需的 npm 依赖由插件管理器处理，无需手动安装。源码开发使用 Node.js 22 或更新版本，并执行 `npm ci --ignore-scripts`。
