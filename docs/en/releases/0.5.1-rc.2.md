# Team Board v0.5.1-rc.2

[简体中文](../../releases/0.5.1-rc.2.md) | **English**

A preview of the simplified page, based on 0.5.0.

## Changes

- Manage review and development runs through Overview, Discussion, Tasks, and Results, opening related records and logs on demand.
- Correct requirement revisions that reused superseded decisions. Rerun affected decisions and downstream tasks while preserving history.
- Remove Agent Teams views and legacy team-task import from the page. Agent Teams can remain disabled; existing team tools and data remain available.
- Read only the enablement setting for the page switch and shorten the Chinese and English setup guides.

## Verification

The current source passed **1621/1621** tests, type checking, and generated-client consistency checks. Relevant interfaces passed real DSH checks, and the page dependency cleanup passed an independent incremental review. Visual appearance and installed interaction testing remain for the preview trial, so this version is published as a prerelease.

## Installation

1. Enable DSH subagents and a fresh-context provider such as `spawn`. Development tasks also need command execution and project check configuration.
2. Download this release's `local-team-board-0.5.1-rc.2.tgz` and install its absolute local path through the DSH plugin manager.
3. Open the Team Board conversation tab, turn on the switch, and create or select a task.

Verify the archive against the attached `SHA256SUMS.txt`. See [dependencies and setup](../dependencies.md) for environment requirements.
