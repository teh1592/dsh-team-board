# Team Board v0.5.0

[简体中文](../../releases/0.5.0.md) | **English**

> **Describe your goal with confidence. Let AI work through it with care.**
>
> Team Board aims to give you room to focus on your goal while AI handles more of the planning, coordination, implementation, and verification, producing code that people can understand and maintain.

The first GitHub source release of Team Board, a plugin for DeepSeek Harness (DSH).

The workflow connects requirements, independent reviews, decisions, implementation, machine checks, independent verification, and targeted rework. It includes `quick@2` and `standard@2`, `review` and `develop` modes, pause/resume, scoped requirement revisions, history imports, and a paginated run panel.

Verified with DSH **0.2.2-rc.1** and Node.js **24.22.3**. The product suite passed **1591/1591** tests before release, along with real-host command and interface verification. A separate pilot passed **14 of 15** tasks; one stopped because a verifier omitted resolved finding IDs. See the [pilot results](../practice-results.md) for the conditions and missing usage records.

Before installing, enable DSH subagents and a fresh-context provider such as `spawn`. Implementation checks need subprocess support; recovery and usage queries use sessionQuery. Legacy team tasks, meetings, and history imports also need official Agent Teams. DSH manages these host components; the Team Board switch is separate.

Download `local-team-board-0.5.0.tgz`, then use DSH's `plugin_manager` to install its absolute local path. Enable the plugin in the Team Board tab. Ajv and Zod are resolved from the manifest. Verify the archive against the attached `SHA256SUMS.txt`.

The source is released under MIT. The GitHub archive adds public documentation, repository metadata, and the license to the previously verified 0.5.0 implementation. Checksums belong to this release's attachments. The [English README](../../../README.en.md) and [dependency guide](../dependencies.md) describe current setup.
