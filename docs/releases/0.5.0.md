Team Board 的首次 GitHub 源码发布，面向 DeepSeek Harness（DSH）。

支持从需求梳理、独立评审、决议，到代码实施、机器检查、独立验证和定向返工的完整流程。提供 quick@2 与 standard@2、review 与 develop 方式，以及暂停恢复、需求局部修订、历史导入和分页运行页面。

已在 DSH 0.2.2-rc.1 / Node.js 24.22.3 验证。发布前产品测试 1591/1591 通过，真实宿主命令与接口验收通过。15 个实际任务试用为 14 项通过、1 项因漏填已修复问题 ID 而停止，使用条件与缺失用量见仓库 docs/practice-results.md。

安装前确认 DSH 已启用 subagents 与全新上下文的 `spawn` provider；实施与机器检查需要 subprocess，恢复和用量查询需要 sessionQuery。使用旧任务板、会议或历史导入时，另需官方 Agent Teams（智能体团队）。这些是 DSH 宿主组件，本仓库不复制其源码；Team Board 自身的开关独立设置。

下载 `local-team-board-0.5.0.tgz` 后，通过 DSH 的 plugin_manager 安装该包的本地绝对路径，再到团队台账页签打开插件开关。Ajv、Zod 按 manifest 解析安装，`SHA256SUMS.txt` 提供附件校验值。

源码按 MIT 许可发布。此包增加公开文档、仓库元数据和许可，运行时实现沿用已验证的 0.5.0；GitHub Release 附件校验值以本次发布为准。
