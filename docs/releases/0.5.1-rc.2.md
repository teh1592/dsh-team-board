# Team Board v0.5.1-rc.2

**简体中文** | [English](../en/releases/0.5.1-rc.2.md)

本版为精简页面的预览版本，基于 0.5.0 更新。

## 变化

- 用总览、讨论、任务、结果四个页签管理评审与开发运行，关联记录和日志按需打开。
- 修复修改需求后继续沿用旧决定的问题，重做受影响的决定与后续任务，保留历史记录。
- 页面移除 Agent Teams 视图和旧团队任务导入入口。Agent Teams 可保持关闭，原有团队工具和数据保留。
- 页面开关只读取启用状态，精简中英文依赖与启用说明。

## 验证

当前源码完整测试 **1621/1621 通过**，类型检查与构建一致性检查通过。相关接口已通过真实 DSH 检查，本次页面依赖清理也通过独立增量复核。实际页面观感和安装后的操作体验留待试用，因此按预发布版本提供。

## 安装

1. 在 DSH 中启用子智能体和全新上下文的 `spawn`。开发任务还需命令执行能力及项目检查配置。
2. 下载此 Release 的 `local-team-board-0.5.1-rc.2.tgz`，通过 DSH 插件管理器安装其本地绝对路径。
3. 打开会话中的 Team Board 页签，打开开关，创建或选择任务。

附件校验值见 `SHA256SUMS.txt`。环境要求见[依赖与启用](../dependencies.md)。
